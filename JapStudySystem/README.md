# 日文学习系统 (JapStudySystem)

一个基于 Java Swing 的日文单词与语法学习工具，支持卡片式浏览、随机测试、掌握度跟踪，以及通过 DeepSeek 进行图片识别批量导入。

## 功能特性

- **卡片式浏览**：以卡片样式展示所有已保存的单词和语法，支持滚动查看
- **添加考察点**：手动新增日语单词或语法条目，语法条目支持例句和例句译文
- **模糊搜索**：输入日文或中文关键词进行查找，支持在线编辑和删除
- **随机测试**：JLPT 分组测试与本地词库动态临时组测试，自动跟踪学习进度
- **图片识别**：通过 DeepSeek 识别图片中的日语内容，批量解析并导入词库
- **数据持久化**：退出时自动保存所有学习数据和测试记录
- **掌握词条归档**：本地临时组结算时，将符合掌握条件的词条完整追加到 `D:/JaStu_mastered.txt`，再从活动词库移除
- **内置 JDK**：无需安装 Java 环境，解压即用

## 3.9.0 本地掌握词条归档

- 本地临时组结束时，符合现有掌握规则（已掌握且本组错误不超过 3 次）的词条会先追加到 `D:/JaStu_mastered.txt`，再从活动词库 `D:/JaStu.txt` 移除。
- 档案为 UTF-8 制表符分隔文本：每行前 12 列保留原词条数据，第 13 列记录带时区的归档时间。文件可直接查看，也可用现有词条解析器读取。
- 若档案文件无法写入，结算会停止，词条仍留在活动词库；修复写入问题后点击“继续测试”即可重试。
- 既有累计掌握数继续保存在活动词库文件头；本功能只归档升级后新结算的词条，不会重建旧版本已经删除的词条内容。

## 3.10.0 本地词库随机练习优化

- 临时组最多15条可测词；词库不超过15条时全部纳入。超过15条时，最近追加的5条必入组，其余按 localId 顺序分为前70%和后30%，各随机抽取最多5条，不足时不跨段补位。
- 组内取消权重：先随机覆盖所有陌生词，再随机练习了解词；每阶段尽量避免连续抽中同一词。已答过的陌生词会等待未出题的陌生词先覆盖。
- 本组错误超过3次的词状态封顶为“了解”，继续答题直到达到 `2 + floor(本组错误数 / 2)` 次正确；之后只完成本组，不归档也不移除，留待后续批次抽取。
- 本组错误不超过3次且达到“掌握”的词，仍在本组结束时归档并从活动词库移除。词条的12列格式和临时组状态文件格式保持兼容。

## 3.8.9 进度与抽题优化

- 本地进度总量按现存词条数加历史累计掌握数计算；当前批次待结算的掌握词计入掌握段，词条结算删除后进度保持连续。待富化词计入现存总量。
- JLPT 分组与本地临时组有两个以上可测词时避免连续抽中同一词，只有一个可测词时允许重复；近期抽中不再增加权重，陌生/了解状态与错题权重保留。
- 本地临时组和 JLPT 分组均保存上次抽中词，重启后继续防连续重复；旧状态与旧分组文件仍可读取。

## 3.8.10 进度条对齐

- 分组与词书/本地词库进度行统一标题列宽度，两条进度条从同一水平位置开始。

## 3.8.11 进度条文案与间距

- 本地进度行标题简化为“词库”，与进度条的间距缩短；累计总量直接标为“累计入库”，不再展示现存数与历史数的计算式。

## 使用方法

### 启动程序

1. 将 `JapStudySystem` 文件夹完整解压到任意位置（建议路径不含中文和空格）
2. 确保 `JapStuSystem启动.bat`、`bin/`、`jre-minimal/` 在同一文件夹下
3. 双击 `JapStuSystem启动.bat` 即可启动

> 无需手动安装 Java 环境，程序使用内置的 JRE 运行。

### 主要功能

#### 查看全部
以卡片样式展示所有已保存的单词和语法。每张卡片显示类型、日文、释义、掌握率；语法卡片额外显示例句和例句译文。卡片上可直接点击**修改**或**删除**。

#### 添加考察点
1. 点击**添加考察点**
2. 输入日文，点击**确认输入**
3. 输入中文释义，点击**确认输入**
4. 选择类型（**单词** / **语法**）
   - 单词：直接添加完成
   - 语法：继续输入例句和例句译文后完成添加

#### 查找考察点
输入日文或中文关键词进行模糊搜索，找到后可进行**修改日文**、**修改释义**、**修改例句**、**修改例句译**、**删除**等操作。

#### 随机测试
JLPT 词书按既有分组测试；本地词库每次随机抽取最多15条已富化词条组成临时组：
1. 点击**随机测试**
2. 看到日文表达后，点击**显示答案**查看释义和例句
3. 根据记忆情况点击**记得**或**不记得**
4. 本地临时组先随机覆盖所有陌生词，再练习了解词；每个阶段内均匀随机，且有其他候选时不连续抽中同一个词
5. 本组错误不超过3次的词，陌生答对一次变为了解，了解阶段达到 `2 + floor(本组错误数 / 2)` 次正确后变为掌握
6. 本组错误超过3次的词状态封顶为了解；继续答到对应正确次数后完成本组，但词条保留在词库且不归档，后续批次仍可抽取。掌握词在本组结束后统一归档并移除
7. 临时组抽取时，最近追加的5条可测词优先入组；其余词按 localId 分成前70%和后30%，各随机抽最多5条。15条及以下全部纳入。
8. JLPT 抽题保持原有规则；近期抽中不再增加权重。

本地词库未富化的新词可以正常手动录入，但不会进入测试，直到富化状态变为已富化。

本地词库进度条总量按“现存词条数＋历史累计掌握数”计算；当前批次已达到掌握但尚未结算删除的词也显示在掌握段。掌握词从词库结算删除时，历史计数同步增加，进度保持连续。待富化词计入现存总量，并单独显示待富化数量。

本地掌握词归档写入 `D:/JaStu_mastered.txt`（UTF-8、制表符分隔）。每行前 12 列与 `D:/JaStu.txt` 的词条格式一致，末列为带时区的归档时间；归档失败时词条不会从活动词库删除，可修复写入问题后重试结算。

#### 图片识别（DeepSeek）
1. 点击**图片识别**，程序自动打开 DeepSeek 网页并复制识别指令
2. 在 DeepSeek 上传包含日语内容的图片
3. 粘贴指令并发送，复制 DeepSeek 的回复
4. 回到程序，粘贴回复并点击**解析并预览**
5. 在预览卡片中确认/修改条目，点击**全部添加到词库**

## JLPT 掌握规则

| 阶段 | 条件 | 所需正确次数 |
|------|------|-------------|
| 初始 | 开始学习 | 5 次 |
| 第 1 次出错 | 累计答错 2 次 | 6 次 |
| 第 2 次出错 | 累计答错 4 次 | 7 次 |
| ... | 每累计答错 2 次 | +1 次 |

当正确次数达到动态要求时，该条目自动视为已掌握，不再出现在随机测试中。

## 数据说明

所有学习数据保存在 `D:/JaStu.txt`，包括：
- 单词/语法条目（日文、中文释义、类型、例句、例句译文）
- 测试次数（examTimes）
- 正确次数（trueTimes）

> 正常点击**保存退出**关闭程序，下次打开时数据完整保留。

## 常见问题

### 双击启动脚本没反应或闪退
检查是否完整解压所有文件，`JapStuSystem启动.bat`、`bin/`、`jre-minimal/` 应在同一文件夹下；确认文件夹路径不含中文或特殊符号。

### 窗口大小不合适
直接拖动窗口边缘自由拉伸调整大小，卡片会自动换行排列。

### 图片识别时浏览器未自动打开
手动访问 [https://chat.deepseek.com/](https://chat.deepseek.com/)，并将识别指令粘贴到对话框中。

### 解析内容格式不正确
请确保 DeepSeek 回复严格按以下格式（制表符分隔）：
```
日文表达[TAB]中文释义[TAB]类型[TAB]例句[TAB]例句翻译
```
若个别条目格式异常，可在预览卡片中手动修改后再添加至词库。
