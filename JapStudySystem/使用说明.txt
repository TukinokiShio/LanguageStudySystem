日文学习系统 JapStuSystem 使用说明

========================
一、程序运行方法
========================
1. 将整个 JapStuSystem 文件夹完整解压到电脑任意位置（建议路径不含中文和空格，如 D:\JapStuSystem）。
2. 确保文件夹内同时包含以下内容：
   - JapStuSystem启动.bat
   - bin 文件夹
   - jre-minimal 文件夹
3. 直接双击【JapStuSystem启动.bat】即可启动程序。
4. 无需手动安装 Java 环境，解压即用。

========================
二、功能按钮介绍
========================
1. 查看全部
   以卡片样式展示所有已保存的单词和语法。每张卡片显示类型、日文、释义、掌握率，语法卡片额外显示例句和例句译文。卡片上可直接点击【修改】或【删除】。

2. 添加考察点
   手动新增日语单词或语法条目。按提示依次输入日文、中文释义，选择类型（单词/语法）；若选语法，还需输入例句和例句译文，完成后自动保存。

3. 查找考察点
   输入日文或中文关键词进行模糊搜索，找到后可进行【修改日文】、【修改释义】、【修改例句】、【修改例句译】、【删除】等操作。

4. 随机测试
   系统随机抽取未完全掌握的内容进行记忆测试。点击【显示答案】查看释义和例句，根据记忆情况点击【记得】或【不记得】。
   【掌握规则】起始需答对 5 次，之后每累计答错 2 次，所需正确次数增加 1 次。当正确次数达到动态要求时，该条目自动从待学列表移除，视为已掌握。

5. 图片识别
   通过 DeepSeek 网页版识别图片中的日语单词或语法。自动打开 DeepSeek 聊天页面并复制识别指令，粘贴回复后可解析出条目列表，支持在预览卡片中修改、删除，确认后可一次性批量添加到词库。

6. 保存退出
   退出程序前自动保存所有数据、测试次数、正确率等信息，关闭后数据不会丢失。

7. 辅助按钮说明
   显示答案：测试模式下查看当前条目的中文释义与例句。
   记得 / 不记得：测试中标记本次是否记住。
   单词 / 语法：添加考察点时选择条目类型。
   修改日文 / 修改释义 / 修改例句 / 修改例句译：对找到的条目进行内容编辑。
   完成修改：确认并保存修改后的内容。
   删除：直接删除当前选中的条目。

========================
三、详细操作步骤
========================
1. 添加考察点
   点击【添加考察点】，上方输入框输入日文（如“場合”），点击【确认输入】；
   再输入中文释义，点击【确认输入】；
   然后点击上方【单词】或【语法】选择类型：
   - 若选【单词】：直接添加完成，提示成功。
   - 若选【语法】：继续输入例句（如“この場合（ばあい）は特別（とくべつ）です。”），点击确认；接着输入例句翻译，点击确认后完成添加。

2. 查看全部条目
   点击【查看全部】，所有单词和语法将以统一高度的卡片展示。语法卡片内容较多时可上下滚动查看完整例句。

3. 查找并编辑条目
   点击【查找考察点】，输入日文或中文关键词搜索；
   找到唯一结果后，可使用上方【修改日文】、【修改释义】、【修改例句】、【修改例句译】等按钮编辑对应字段，改完后点击【完成修改】保存；
   也可直接点击【删除】进行删除。

4. 随机背诵测试
   点击【随机测试】，系统随机出现一条日文表达；
   点击【显示答案】查看中文释义与例句（若有）；
   根据实际记忆情况点击【记得】或【不记得】；
   系统自动计算正确次数与所需次数，达到掌握要求后条目自动移除。

   掌握规则示例：
   - 初期需要连续答对 5 次。
   - 若过程中累计答错 2 次，所需答对次数变为 6 次。
   - 累计答错 4 次，所需答对次数变为 7 次，以此类推。
   每次测试都会显示当前进度和还需答对次数。

5. 图片识别（网页版）
   点击【图片识别】进入识别界面，浏览器自动打开 DeepSeek 页面，识别指令已复制到剪贴板。
   操作流程：
   （1）在 DeepSeek 对话框中上传包含日语内容的图片；
   （2）在输入框粘贴（Ctrl+V）已复制的指令，发送消息；
   （3）复制 DeepSeek 回复的全部内容（Ctrl+C）；
   （4）回到本程序，在左侧文本框中粘贴回复，点击【解析并预览】；
   （5）右侧卡片区显示识别结果，可点击【修改】重新编辑各字段，或【删除】不需要的条目；
   （6）确认无误后点击底部【全部添加到词库】，一次性导入所有单词/语法；
   （7）点击【返回主界面】回到卡片总览。

========================
四、数据保存说明
========================
所有学习数据（单词/语法、测试次数、正确记录）自动保存在 D:\JaStu.txt。
正常点击【保存退出】关闭程序，下次打开时数据完整保留，不会丢失。
如需备份，直接复制 D:\JaStu.txt 至其他位置即可，恢复时覆盖回原路径。

========================
五、常见问题
========================
1. 双击启动.bat没反应或闪退
   检查是否完整解压所有文件，JapStuSystem启动.bat、bin、jre-minimal 应在同一文件夹下；
   确认文件夹路径不含中文或特殊符号。

2. 窗口大小不合适
   直接拖动窗口边缘自由拉伸调整大小，卡片会自动换行排列。

3. 条目太多不好找
   使用【查找考察点】功能，输入任意日文或中文关键词即可模糊搜索。

4. 图片识别时浏览器未自动打开
   手动访问 https://chat.deepseek.com/ ，并将以下指令复制到对话框中（程序已自动复制，可检查剪贴板）：
   “请识别图片中的日语内容，区分单词或语法。
   对每个项目输出一行，每行包含5个字段，用制表符分隔，不要输出任何额外说明。

   字段顺序：日文表达[TAB]中文释义[TAB]类型（单词 或 语法）[TAB]例句[TAB]例句翻译

   格式规则：
   【单词】
     - 如果是汉字词：日文表达只写汉字；中文释义写“单词本身（假名）+ 空格 + 中文意思”。
     - 如果是非汉字词：日文表达写原词；中文释义只写中文意思。
   【语法】
     - 日文表达写带假名注音的语法条目；中文释义写中文意思；必须提供例句和例句翻译。

   请严格按照上述格式输出。”

5. 解析出的内容格式不正确
   请确保 DeepSeek 回复严格按上述指令格式，每行包含日文表达[TAB]中文释义[TAB]类型[TAB]例句[TAB]例句翻译。
   若个别条目格式异常，可在右侧预览卡片中手动修改后再添加至词库。
