# LanguageStudySystem

多语言学习系统集合，基于 Java Swing 开发，支持日文、英文、西班牙文的学习与记忆测试。

每个语言系统均为独立可运行的完整程序，内置 JDK，解压即用，无需安装 Java 环境。

---

## 系统列表

| 系统 | 目录 | 说明 |
|------|------|------|
| 日文学习系统 | `JapStudySystem/` | 日语单词与语法学习 |
| 英文学习系统 | `EnglishStudySystem/` | 英语单词与语法学习 |

---

## 功能特性

各语言系统功能一致，均包含：

- **卡片式浏览**：以卡片样式展示所有已保存的单词和语法，支持滚动查看
- **添加考察点**：手动新增单词或语法条目，语法条目支持例句和例句译文
- **模糊搜索**：输入关键词进行查找，支持在线编辑和删除
- **随机测试**：基于掌握规则的智能抽查，自动跟踪学习进度
- **图片识别**：通过 AI（DeepSeek）识别图片中的外语内容，批量解析并导入词库
- **数据持久化**：退出时自动保存所有学习数据和测试记录
- **内置 JDK**：无需安装 Java 环境，解压即用

## 快速开始

### 启动程序

1. 将对应语言系统的文件夹完整解压到任意位置（建议路径不含中文和空格）
2. 确保文件夹内同时包含以下内容：
   - `XXXStuSystem启动.bat`（启动脚本）
   - `bin/`（包含打包好的 JAR）
   - `jdk-24/`（内置 JDK 运行环境）
3. 双击启动脚本即可运行

> 以日文系统为例：双击 `JapStudySystem/JapStuSystem启动.bat`

## 使用说明

### 查看全部条目

点击**查看全部**，所有单词和语法以卡片形式展示。每张卡片显示类型、外文、释义、掌握率；语法卡片额外显示例句和例句译文。

### 添加考察点

1. 点击**添加考察点**
2. 输入外文表达，点击**确认输入**
3. 输入中文释义，点击**确认输入**
4. 选择类型（**单词** / **语法**）
   - 单词：直接添加完成
   - 语法：继续输入例句和例句译文后完成添加

### 查找与编辑

点击**查找考察点**，输入外文或中文关键词进行模糊搜索。找到结果后可：
- 修改日文/英文/西班牙文
- 修改释义
- 修改例句（如有）
- 修改例句译文（如有）
- 删除条目

### 随机测试

1. 点击**随机测试**，系统随机抽取未掌握条目
2. 看到外文表达后，点击**显示答案**查看释义和例句
3. 根据记忆情况点击**记得**或**不记得**
4. 达到掌握要求后，该条目自动从待学列表移除

#### 掌握规则

| 阶段 | 条件 | 所需正确次数 |
|------|------|-------------|
| 初始 | 开始学习 | 5 次 |
| 第 1 次出错 | 累计答错 2 次 | 6 次 |
| 第 2 次出错 | 累计答错 4 次 | 7 次 |
| ... | 每累计答错 2 次 | +1 次 |

### 图片识别（AI 辅助导入）

1. 点击**图片识别**，程序自动打开 DeepSeek 网页并复制识别指令到剪贴板
2. 在 DeepSeek 上传包含外语内容的图片
3. 粘贴指令（Ctrl+V）并发送，复制 DeepSeek 的回复
4. 回到程序，在左侧文本框粘贴回复，点击**解析并预览**
5. 在右侧预览卡片中确认/修改条目，点击**全部添加到词库**

## 数据存储

各系统的学习数据分别保存在对应的文本文件中：

| 系统 | 数据文件 |
|------|---------|
| 日文 | `D:/JaStu.txt` |
| 英文 | `D:/EnStu.txt` |

数据文件包含：
- 单词/语法条目（外文表达、中文释义、类型、例句、例句译文）
- 测试次数（`examTimes`）
- 正确次数（`trueTimes`）

> 正常点击**保存退出**关闭程序，下次打开时数据完整保留。
> 备份时直接复制对应的 `.txt` 文件即可。

## 常见问题

### 双击启动脚本没反应或闪退

检查是否完整解压所有文件，启动脚本、`bin/`、`jdk-24/` 应在同一文件夹下；确认文件夹路径不含中文或特殊符号。

### 窗口大小不合适

直接拖动窗口边缘自由拉伸调整大小，卡片会自动换行排列。

### 图片识别时浏览器未自动打开

手动访问 [https://chat.deepseek.com/](https://chat.deepseek.com/)，并将程序复制的识别指令粘贴到对话框中。

### 解析内容格式不正确

请确保 AI 回复严格按以下格式（制表符 `\t` 分隔）：

```
外文表达[TAB]中文释义[TAB]类型[TAB]例句[TAB]例句翻译
```

若个别条目格式异常，可在预览卡片中手动修改后再添加至词库。
