使用说明（英语单词系统 V2.2.0）

========================
一、程序运行方法
========================
1. 把整个压缩包完整解压到电脑任意文件夹
2. 必须保证 启动.bat 、bin文件夹、jdk-24文件夹 在同一个目录里
3. 直接双击 启动.bat 即可打开程序
4. 对方电脑不需要安装Java环境，解压就能用

========================
二、功能按钮介绍
========================
1. 查看全部
   以卡片样式展示所有已保存单词，每张卡片支持单独修改、删除，同时显示单词释义、考核次数、正确率。
   顶部切换栏可在「查看等级词书 / 查看本地词库」之间切换，方便对比两类词库。

2. 添加单词
   可以手动新增英语单词和对应的中文释义，按提示依次输入英文、中文即可自动保存。
   添加成功后自动进入下一个单词，可连续录入，无需反复点击进入。

3. 查找单词
   输入英文单词或中文释义关键字，可模糊搜索对应单词，找到后支持修改单词、修改释义、删除单词。

4. 测试本地词库
   系统从本地词库（D:/EngStu.txt）随机抽取单词进行记忆背诵测试，自动记录考核次数和答对次数，统计正确率。
   【掌握规则】起始需答对5次，之后每累计答错2次，所需正确次数增加1次。
   达到动态掌握要求后，该单词会自动从待学列表移除，视为已掌握。
   与「等级词书」可自由来回切换，互不干扰。

5. 等级词书
   进入 CET4 / CET6 / IELTS / TOEFL 分级词库学习（共两千余词）。
   顶部「CET4」按钮为等级切换，可在四个等级之间随意切换；
   测试时支持「继续测试」「掌握单词」「进入下一组」功能，并有双进度条显示整体词书与当前分组的掌握情况。

6. 图片识别
   将包含英语单词的图片直接拖入识别区，系统自动调用本地部署的 AI Agent 进行识别，
   解析出单词列表并批量加入本地词库；右下角同时保留「网页版」可选入口，可手动使用 DeepSeek 网页版识别。
   支持在预览卡片中修改、删除，确认后一次性批量添加。
   注意：需在图片识别界面先配置 API 地址、Key 与视觉模型（Model）。

7. 使用说明
   点击可查看本系统的完整功能分类说明（词库管理 / 学习测试 / 数据保存），随时了解各按钮用途。

8. 保存退出
   退出程序前自动保存所有单词数据、测试记录、正确率信息，关闭后数据不会丢失。

9. 辅助按钮说明
   显示答案：测试模式下查看单词中文释义
   记得 / 不记得：标记本次背诵是否记住，用于统计正确率
   修改单词、修改释义：对搜到的单词进行内容编辑
   完成修改：确认并保存修改后的内容
   删除该单词：直接删除当前选中的单词（等级词书不支持删除，可用「掌握单词」跳过）
   继续测试（等级词书）：开始或继续当前分组的等级测试
   掌握单词（等级词书）：将当前单词直接标记为已掌握，不再出现于测试
   进入下一组（等级词书）：当前组全部掌握后自动进入下一组

========================
三、详细操作步骤
========================
1. 添加单词
   点击【添加单词】，上方输入框输入英文单词，点击【输入完成】；
   再输入中文释义，点击【输入完成】，提示添加成功后会自动进入下一词，可继续录入。

2. 查看全部单词
   点击【查看全部】，所有单词以卡片展示，每张卡片可点击【修改】或【删除】单独操作；
   顶部切换栏可一键在「本地词库」与「等级词书」之间切换查看。

3. 查找并编辑单词
   点击【查找单词】，输入英文或中文关键词搜索；
   找到唯一单词后，可选择【修改单词】、【修改释义】，改完点击【完成修改】保存；
   也可直接点击【删除该单词】进行删除。

4. 本地词库背诵测试
   点击【测试本地词库】，自动出现本地词库中的英文单词；
   点击【显示答案】查看中文意思；
   根据自己记忆情况点击【记得】或【不记得】；
   每次测试后系统会显示本次结果及当前掌握进度。
   掌握规则：初始需要答对5次，每累计答错2次，所需答对次数增加1次。
   当正确次数达到当前所需次数时，单词自动移除，表示已掌握。

5. 等级词书学习
   点击【等级词书】进入分级学习，顶部「CET4」按钮可在 CET4 / CET6 / IELTS / TOEFL 间切换；
   点击【继续测试】开始或继续当前分组的测试；
   每词显示英文，点击【显示答案】看释义，选【记得】/【不记得】；
   记不住或想跳过的单词可点击【掌握单词】直接标记为已掌握；
   当前分组全部掌握后，系统自动进入下一组，双进度条实时反映整体与分组进度。

6. 图片识别（AI Agent 自动 + 拖入图片）
   点击【图片识别】进入识别界面；
   将包含英语单词的截图直接拖入左侧识别区（也可点击选择图片）；
   系统自动调用本地部署的 AI Agent 识别图片，返回单词列表；
   右侧卡片区显示识别结果，可以单独【修改】或【删除】卡片；
   确认无误后，点击底部【将以上单词全部添加到词库】，一次性保存到本地词库。
   如需改用网页方式，可点击右下角【网页版】按钮，按旧流程使用 DeepSeek 网页版识别。

========================
四、数据保存说明
========================
所有单词、测试次数、答对记录、正确率都会自动保存在本地文件里，
正常点击【保存退出】关闭程序，下次打开所有数据都还在，不会丢失。
本地词库自动保存至 D:/EngStu.txt；等级词书的学习进度保存至工作目录。

========================
五、常见问题
========================
1. 双击启动.bat没反应
   检查是否完整解压所有文件，不要单独挪动某个文件夹；
   确保启动.bat、bin、jdk-24三者在同一个文件夹。

2. 窗口大小不合适
   可以直接拖动窗口边缘，自由拉伸调整大小。

3. 单词太多不好找
   直接使用查找单词功能，输入任意关键字即可模糊搜索。

4. 图片识别失败或返回错误
   检查图片识别界面是否已正确配置：API 地址、API Key、以及支持视觉输入的模型（Model，例如带视觉能力的模型）。
   图片过大时会自动压缩后发送；若仍报错，错误弹窗会显示 API 返回的完整内容，可据此排查。
   也可点击右下角【网页版】按钮，改用 DeepSeek 网页版手动识别。

5. 解析出的单词格式错误
   确保 AI 返回的单词列表为「英文单词[TAB]词性. 中文释义」格式，每行一个单词。
   若仍有问题，可在预览卡片中手动修改内容后再添加。

6. 等级词书与本地词库数据混淆
   两者相互独立：「测试本地词库」只测试本地词库，「等级词书」只学习等级词库；
   点击顶部对应按钮即可自由切换，互不影响。
