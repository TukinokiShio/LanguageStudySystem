# LanguageStudySystem

多语言学习系统集合，基于 Java Swing 开发。当前包含**日语学习系统（JSS）**与**英语学习系统（ESS）**两套独立应用，各版本归档统一通过 Git LFS 管理。

---

## 项目结构

| 目录 | 说明 |
|---|---|
| `JapStudySystem/` | 日语学习系统（JSS）源码与编译产物 |
| `JSS_history/` | JSS 全部历史版本归档（zip / Setup 安装包 / 构建日志），经 Git LFS 管理 |
| `EnglishStudySystem/` | 英语学习系统（ESS）源码与编译产物 |
| `ESS_history/` | ESS 全部历史版本归档（zip / Setup 安装包 / 构建日志），经 Git LFS 管理 |
| `.gitattributes` | Git LFS 跟踪规则（`*.zip` / `*.exe`）|
| `.gitignore` | 忽略 jre-minimal、jdk-24、.class 等 |

---

## 日语学习系统（JSS）

- **最新版本**：V3.10.1
- **JSS 默认安装目录**：`D:\SHIO_LANGUAGE\jss`。后续 JSS 安装包默认并固定使用此目录。
- **技术栈**：Java Swing GUI · JDK 24
- **启动方式**：运行 `JapStudySystem/run.bat`（或 `run.vbs`）启动；也可直接运行 `bin/JapanStudySystem.jar`
- **核心功能**
  - 卡片式浏览：以卡片样式展示全部单词与语法条目，支持滚动查看
  - 图片识别：通过 AI（DeepSeek）识别图片中的外语内容，批量解析并导入词库
  - JLPT 辞典系统：内置 N1–N5 级别日语辞典数据，支持分级词汇学习
  - 分组测试：基于掌握规则的智能抽查（JLPT 分组生成器 `GroupGenerator`）
  - 键盘快捷键：本地测试、JLPT、添加考察点全流程键盘操作（回车=显示答案/记得/继续，←/→/空格导航；添加考察点 Ctrl+回车确认、←/→ 选类型）
  - 添加考察点接续优化：单次添加成功后自动进入下一次添加，不清空已打印的成功提示，无需手动重置
  - JLPT 词书例句渲染：测试与卡片展示例句（振假名注音）+ 第二例句（v3.6.0）
  - 防连测重复：JLPT 分组与本地临时组可测词 ≥2 时，下一题不与刚测过的词重复；上次抽题跨重启保留
  - 分组随机抽题：取消近期抽中加权，保留陌生/了解和错题权重，降低个别词反复被抽中的倾向（v3.8.9）
  - 本地词库动态测试：可测词按 localId 顺序分成前60%、中间30%和后10%，每段随机抽取最多5条，不建立静态分组文件
  - 本地词库分阶段随机练习：先覆盖陌生词再练习了解词，组内均匀随机且尽量避免连续重复；超过3次错误的词继续答到本组正确次数后仅记为了解并保留
  - 本地词库三态熟练度：正常达到掌握的词在本组结束后归档并移除；困难词保持了解状态留在词库，后续批次仍可抽取
  - 本地已掌握词条归档：结算移除前将完整词条追加到 `D:\JaStu_mastered.txt`，同时保留历史掌握计数
  - 本地词库历史掌握计数：累计记录已掌握并从临时组结算的词条，跨批次与重启保留（v3.8.8）
  - 本地词库进度条：总量按现存词条加历史掌握数计算，掌握段包含历史累计和当前批次待结算掌握词，结算前后进度连续（v3.8.9）
  - 本地进度行标题简化为“词库”，进度条更贴近行标题；累计总量标为“累计入库”（v3.8.11）
  - 词书与分组进度条标题列统一宽度，两条进度条左边缘对齐（v3.8.10）
  - 本地词库富化状态：待富化词不参与测试，手动新增或编辑内容会自动回到待富化
  - 掌握度统计：掌握 / 了解 / 陌生三色可视化
  - 本地测试结果页：保留单词与释义，显示累计考核、正确次数、正确率、达到下一状态所需答对次数及本组升级/保留规则，不重复显示例句
  - 答案页振假名例句：按文本标签首选宽度留出空间，避免普通片段末尾被省略（v3.8.7）
  - 本地例句译文：按 JLPT 格式补充疑难语法与搭配简释
- **历史版本**：V1.3.5 · V1.5.4 · V1.5.5 · V2.0.3 · V3.0.5 · V3.1.1 · V3.2.0 · V3.3.2 · V3.4.0 · V3.5.0 · V3.6.0 · V3.7.0 · V3.8.0 · V3.8.2 · V3.8.3 · V3.8.4 · V3.8.5 · V3.8.6 · V3.8.7 · V3.8.8 · V3.8.9 · V3.8.10 · V3.8.11 · V3.9.0 · V3.9.1 · V3.10.0 · V3.10.1（详见 `JSS_history/`）

## 英语学习系统（ESS）

- **最新版本**：V2.2.0
- **技术栈**：Java Swing GUI · JDK 24
- **启动方式**：运行 `EnglishStudySystem/` 下启动脚本；或执行编译产物 JAR
- **核心功能**
  - 等级生成器（`EngLevelGenerator`）：按掌握率生成分级练习
  - 分组生成器（`EngGroupGenerator`）：按考试体系分组词汇
  - 分级词库：内置 CET4 / CET6 / IELTS / TOEFL 分组词汇数据
  - 词库切换：一键在「等级词库 / 本地词库」间切换查看
  - 本地词库测试、使用说明内置面板
  - 掌握度统计与智能复习
- **历史版本**：V2.1.0 · V2.1.1 · V2.1.5 · V2.2.0（详见 `ESS_history/`）

## 版本归档与 Git LFS

所有历史版本的压缩包与安装包（`.zip` / `.exe`）体积较大，已通过 **Git LFS** 管理。克隆本仓库后需先执行：

```bash
git lfs install
git lfs pull
```

以正确拉取 `JSS_history/` 与 `ESS_history/` 中的归档文件。
